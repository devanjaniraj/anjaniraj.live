## 🚀 Getting Started

### For Local Development

**1. Clone the repository**
```bash
git clone https://github.com/devanjaniraj/anjaniraj.live.git
cd anjaniraj.live
```

**2. Open in your browser**
- **Option A (Simplest):** Double-click `index.html`
- **Option B (With Live Server):** Use VS Code Live Server extension
- **Option C (HTTP Server):**
  ```bash
  python3 -m http.server 8000
  # Visit http://localhost:8000
  ```

**3. Make it your own**
- Edit `index.html` with your content
- Customize colors/fonts in `styles/style.css`
- Update `js/script.js` for your interactions

- [ ] Replace images in `assets/images/`

## 🌐 Deploy to GitHub Pages

### If you forked this repository:

1. **Rename your fork** to `yourusername.github.io`
   - Go to Settings → General → Repository name
   - Change to `yourusername.github.io` (replace with your username)

2. **Enable GitHub Pages** (usually automatic after renaming)
   - Go to Settings → Pages
   - Verify it's deploying from `main` branch

3. **Push your changes** to the `main` branch
   ```bash
   git add .
   git commit -m "Customize site with my information"
   git push origin main
   ```

4. **Visit your site**
   - Navigate to `https://yourusername.github.io`
   - Your site will be live in 1-2 minutes

### If you want to use a custom domain:

1. **Update CNAME file** with your domain
   ```
   yourdomain.com
   ```

2. **Configure DNS** settings with your domain provider
   - Add `CNAME` record pointing to `yourusername.github.io`
   - Or add `A` records pointing to GitHub Pages IP addresses

3. **Push your changes** to GitHub
   ```bash
   git add CNAME
   git commit -m "Add custom domain"
   git push origin main
   ```

4. **Verify** in repository Settings → Pages
